# Vibe Coding Notes

> Vibe Coding = describe your intent in natural language and let AI handle the heavy lifting
> (scaffolding, implementation, bug fixing), while you steer the direction and review the results.

## A few takeaways

1. **Get it running first, then make it good**: start with a working version, then iterate on details.
2. **Small steps**: change one thing at a time, verify, then continue.
3. **Let AI fix itself**: paste the error back and it often heals on its own.

```python
# A minimal runnable example: smooth a sequence of numbers
import numpy as np

def smooth(x, w=3):
    kernel = np.ones(w) / w
    return np.convolve(x, kernel, mode='same')

print(smooth([1, 5, 2, 8, 3]))
```

## When it doesn't fit

- Scenarios where correctness is critical and hard to test automatically;
- Low-level logic that needs deep domain expertise.
